# Day 10 - Introduction to JavaScript

## Project Overview

This project is created as part of the Tech Fellows Day 10 practical task. It introduces the basics of JavaScript and demonstrates how JavaScript connects with HTML and displays output using console.log().

## Learning Objectives

- Understand what JavaScript is.
- Learn how to connect an external JavaScript file with HTML.
- Practice console.log().
- Display text, numbers, and calculations.
- Understand the browser console.

## Files Included

- index.html - Contains the basic HTML structure.
- script.js - Contains JavaScript code and console outputs.
- README.md - Contains project information and instructions.

## Task 5 - Theory Questions

### 1. What is JavaScript?

JavaScript is a programming language used to make websites interactive and dynamic. It helps developers add features like buttons, animations, and form validation.

### 2. What is the difference between HTML, CSS, and JavaScript?

- HTML is used to create the structure of a webpage.
- CSS is used to design and style the webpage.
- JavaScript is used to add functionality and interactivity.

### 3. Why do websites use JavaScript?

Websites use JavaScript to make pages interactive and dynamic. It allows users to interact with buttons, forms, menus, and other elements.

### 4. What is the purpose of the script element in HTML?

The script element is used to connect or write JavaScript code in an HTML document. It allows the browser to execute JavaScript.

### 5. What is the browser console, and how do you open it?

The browser console is a developer tool used to view JavaScript output, messages, and errors. We can open it by pressing F12 and selecting the Console tab.

## How to Run the Project

1. Open the project folder.
2. Open index.html in a web browser.
3. Right-click on the webpage and select Inspect.
4. Open the Console tab.
5. View the JavaScript output.
