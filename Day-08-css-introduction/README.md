Project Description

This project demonstrates the use of CSS to style a personal website using an external stylesheet. The same CSS file is connected to both Home and About pages to maintain a consistent design.

Tasks Completed

Task 1 – Connect CSS

- Created an external stylesheet named "style.css".
- Linked the stylesheet to "index.html" and "about.html".
- Verified that CSS styles are applied correctly.

Task 2 – Style Your Pages

- Applied Arial font-family.
- Added background and text colors.
- Centered the main headings.
- Set paragraph font-size and line-height.
- Added borders to content cards, images and header elements.

Task 3 – Keep Both Pages Consistent

- Connected the same stylesheet to both pages.
- Maintained consistent colors, typography and layout.
- Tested navigation between Home and About pages.

Task 4 – Experiment

Two improvements were tested:

1. Changed the background color to "#f7f4fb" for better visual clarity.
2. Increased paragraph font-size to "17px" for improved readability.
