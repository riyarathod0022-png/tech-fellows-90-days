# Day 10 - QR Code Component

## Project Overview
This project is a responsive QR Code Component built using HTML and CSS as part of the Tech Fellows 90 Days Internship.

The design is inspired by the Frontend Mentor QR Code Component challenge.

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Outfit)

## Features
- Clean and modern UI design
- Centered QR Code card
- Responsive layout for desktop and mobile screens
- Rounded corners and subtle shadow
- Simple and user-friendly design

## Project Structure
- index.html - Main HTML structure
- style.css - Styling and responsive design
- Images - QR Code image
- Screenshot - Desktop and mobile screenshots

## Screenshots
Desktop and mobile screenshots are included in the Screenshot folder.

## Learning Outcomes
- Understanding HTML structure
- Working with CSS Flexbox
- Using media queries for responsiveness
- Styling cards, images and typography
