Day 06 - Semantic HTML & Accessibility Review

Project Overview

This project focuses on reviewing and improving the semantic structure and basic accessibility of my existing Day 2 Student Profile Website and Day 5 Student Registration Form.

Tasks Completed

- Reviewed semantic HTML elements.
- Checked heading hierarchy.
- Reviewed image alternative text.
- Tested navigation and external links.
- Checked form labels and input controls.
- Performed keyboard-only navigation testing.
- Reviewed table structure and page content.
- Tested mobile responsiveness.
- Created an accessibility audit log.

Files Included

- README.md
- accessibility-audit.md

Testing

Both websites were tested successfully using keyboard navigation and mobile screen testing.

Conclusion

This review helped me understand the importance of semantic HTML and web accessibility while creating user-friendly websites.
