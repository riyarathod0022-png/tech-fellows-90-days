Day 05 - HTML Forms & Inputs

Project: Student Registration Demo

What I Built

I created a responsive Student Registration Demo Form using HTML and CSS. It includes name, email, age, course selection, study mode, learning goals, and a practice-data confirmation checkbox.

Validation Checks Tested

1. Tested empty required fields and observed browser validation messages.
2. Tested invalid email addresses and age limits (below 16 and above 100).

Bug Fixed

I temporarily changed the Full Name label's for attribute to test the label connection. The label stopped focusing the input field. I fixed it by restoring the correct matching id.

Why Client-Side Validation Is Not Enough

Client-side validation can be bypassed or changed by users. Real applications must also validate data on the server to protect information and ensure correct data.

One Future Improvement

In the future, I would like to connect the form to a backend and database so that registration details can be stored securely.

What I Learned

I learned how to create accessible HTML forms, connect labels with inputs, use different input types, apply validation attributes, test browser validation, and fix label-related bugs.
