Day 12 – Registration Form Typography

Project Overview

This project is an improved Student Registration Form created using HTML and CSS. The main focus of Day 12 is CSS typography, font styling, readability, and text presentation.

Technologies Used

- HTML5
- CSS3
- Google Fonts

Typography Features

- Poppins font for the main heading.
- Inter font for body text and form content.
- Different font sizes and font weights.
- Improved line height and letter spacing.
- Styled labels, placeholders, and helper text.
- Text transformation on the Register button.
- Link pseudo-classes: ":link", ":visited", ":hover", ":focus", and ":active".
- Responsive typography for smaller screens.

How to Run

1. Open the project folder in Visual Studio Code.
2. Open "index.html".
3. Run the file using Live Server.
4. View the Student Registration Form in your browser.

Learning Outcome

Learned how to use CSS typography properties to improve the appearance, readability, and overall presentation of a web form.
