Day 12 – CSS Typography

Tech Fellows | 90-Day MERN Internship

Overview

This project demonstrates CSS Typography concepts, including font families, Google Fonts, font-size units, text properties, link states, form typography and readability.

Tasks Completed

1. Font Stacks: Compared sans-serif, serif and monospace font families.
2. Google Fonts: Integrated Poppins and Inter using CSS variables.
3. Font Size Units: Practiced px, em, rem and nested em calculations.
4. Type Scale and Readability: Created heading sizes, paragraph spacing and line-height demonstrations.
5. Text Properties: Applied uppercase, italic, text-shadow, text-indent and different font weights.
6. Link States: Practiced link, visited, hover, focus and active states using LVHA order.
7. Form Typography: Styled form controls using "font: inherit" and placeholder styling.
8. Debug Challenge: Identified and corrected seven CSS mistakes with comments.

Technologies Used

- HTML5

- Google Fonts
