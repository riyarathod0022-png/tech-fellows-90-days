## About This Project

This project demonstrates important CSS concepts through eight practical tasks. It explores how CSS rules work, how styles are inherited, how colors can be represented, and how CSS variables help maintain a consistent design.

## Tasks Completed

1. **Inheritance:** Explored inherited properties, body styling and the `inherit` keyword.
2. **Specificity Battle:** Compared element, class, ID and `!important` rules.
3. **Source Order:** Tested how the order of CSS rules affects styling.
4. **CSS Color Formats:** Demonstrated Named, HEX, 3-digit HEX, RGB, RGBA and HSL.
5. **HSL Shades:** Created five blue shades using different lightness values.
6. **Transparency:** Compared RGBA transparency with the opacity property.
7. **CSS Variables:** Used custom properties to create a reusable color theme.
8. **Debug Challenge:** Identified and corrected six CSS mistakes.
