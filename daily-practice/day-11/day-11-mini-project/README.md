Student Registration Form

Project Overview

A simple and responsive Student Registration Form created using HTML and CSS.

Features

- Full Name, Email Address and Password fields
- Required field validation
- Password minimum length validation
- Input focus effect
- Button hover effect
- Responsive design
- CSS variables for consistent styling
- Accessible colour contrast

Technologies Used

- HTML5
- CSS3

Project Structure

- "index.html" – Registration form structure
- "css/style.css" – Styling and responsive design
- "Screenshots/" – Desktop and mobile screenshots
