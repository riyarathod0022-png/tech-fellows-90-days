# Day 09 - CSS Selectors, Margin, Padding & Box Model

## Project Description
This project is an improved version of my Day 07 Personal Website. CSS is used to make both Home and About pages more attractive, consistent, and easy to read.

## Features
- Styled Home and About pages
- Element, Class, and ID selectors
- Margin and Padding for proper spacing
- Borders and rounded corners
- CSS Box Model implementation
- Responsive layout
- Consistent Chocolate Brown theme
- Styled profile image and navigation

## Technologies Used
- HTML5
- CSS3

## Project Files
- `index.html` - Home page
- `about.html` - About page
- `style.css` - Stylesheet
- `images/` - Profile image
- `Screenshots/` - Project screenshots

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Navigate between Home and About pages.

## Concepts Practiced
- CSS Element Selector
- CSS Class Selector
- CSS ID Selector
- Margin and Padding
- Border and Border Radius
- Box Sizing
- Box Model
